# 插件 / 技法 / 工具

> **目的**：放三类外挂——技法参考、第三方工具登记、值得留档的代码。

| 子目录 | 放什么 |
|---|---|
| `设计参考/` | 跨项目复用的技法（排版、图示、配色） |
| `第三方工具/` | 装了什么、从哪装、配置在哪 |
| `源码归档/` | 自己写的脚本/插件，能直接重新装的副本 |

## 使用约定

1. **工具登记写全四列**：是什么 / 从哪获得 / 本机位置 / 备份位置。
   「从哪获得」要写**能重新拿到它的那条路**，不写"某次搜到的网页"。
2. **第三方源码一个字都不改**——改了就不是备份了。
3. **技法先进项目，用第二次再提上来。**
