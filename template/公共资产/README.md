# 公共资产（跨项目复用）

> **目的**：放**换个项目还一样用**的东西。只对一个项目成立的，不要放这里——它会绑住别的项目。

## 放什么

| 子目录 | 放什么 |
|---|---|
| `操作手册/` | 怎么做：分主题的操作说明 |
| `自总结sop/` | 跨项目一样的流程（步骤 + 坑） |
| `插件/` | 技法参考、第三方工具登记、代码快照 |

## 使用约定

1. **判据是「跨项目」**：只用一次的先放项目里，用过三次再提上来。
2. **从项目级提上来的，原位置留一行指针**（"已移到 公共资产/X.md"），不要直接删。
3. **每份文件开头写"为了什么"**，否则读的人不知道什么时候该变通。
