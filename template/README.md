# 记忆库 · 入口

> **这份文件是为了什么**
>
> **目的**：只回答一个问题——**这次该看哪几份？** 不写规则、不写教训。
>
> **不做会怎样**：规则会越写越多，而你每次都要重读一遍才知道该看哪份，最后干脆不看。

---

## 一、五个位置

| 位置 | 管什么 | 什么时候看 |
|---|---|---|
| `全局工作流.md` | **做事的顺序**：先做什么、交付什么 | 每次开工 |
| `全局公约.md` | **产出必须什么样** | 写东西、做界面时 |
| `全局工作提示.md` | **哪类活用哪个工具** | 遇到"这件事用什么做" |
| `公共资产/` | 跨项目复用的手册、流程、技法 | 具体操作拿不准时 |
| `公共经验/用户评价/` | **以前这么做被否过吗** | **开工时必看**（最容易跳过） |
| `项目/<项目>/` | 这个项目的档案、公约、产物 | 每次进这个项目 |

---

## 二、开工四步

每次开始实质工作前，按顺序做：

1. **认路**：读本文件，确认这次该看哪几份。
2. **认规矩**：读 `全局工作流.md`；这次涉及写作/界面，再读 `全局公约.md` 相关几条。
3. **查历史**：打开 `公共经验/用户评价/README.md`，对一眼**这类活以前被否过什么**。
   > 这一步最容易跳过，也最容易重犯。跳过它，前面两步白读。
4. **认项目**：读该项目的 `项目档案.md` 和 `项目公约.md`；有 `验收清单.md` 的，看一眼上次到哪了。

最后才动手。

---

## 三、新增内容时

| 写什么 | 放哪 |
|---|---|
| 这次学到的做法 | 项目 `项目资产/思考产物/` |
| 这条路被否掉了 | `公共经验/用户评价/厌恶/`（并加进索引） |
| 反复做过三次的流程 | `公共资产/自总结sop/` |
| 换项目还用的操作说明 | `公共资产/操作手册/` |
| 只对这个项目成立的要求 | 项目 `项目公约.md` |

**每新增一类文件，必须同步更新本文件的索引**——否则它等于不存在。
