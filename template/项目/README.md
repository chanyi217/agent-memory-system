# 项目

> **目的**：每个独立的工作单元一个文件夹。**一个项目一个**，不按任务分。

## 每个项目的结构

```
<项目>/
├── 项目档案.md        目的是什么、给谁做、演进过程、东西在哪
├── 项目公约.md        只管这个项目的硬约束（可以没有）
└── 项目资产/
    ├── 用户提问原文.md  逐字记录
    ├── 验收清单.md      要交付什么、怎么验
    ├── 思考产物/        .md 文档
    ├── 过程产物/        脚本、数据、截图
    └── 成果产物/        交付物
```

## 新建项目的条件

1. 这里确实没有对应文件夹——**按内容判断，不按字面名**（"X 编辑器"和"X"可能是同一个）；
2. 拿不准就**问，不要猜着新建**。

**多建一个项目的代价是历史被劈成两半**，远大于问一句。

## 新建时一次建全

七样一次建齐（档案 / 公约 / 提问原文 / 验收清单 / 三个产物目录）。

> 只建被要求的那一个，其余就永远缺：**产物该放哪依赖目录存在**，目录不在，东西就会被顺手留在原地。

## 开工前读三样

项目档案、项目公约（有的话）、上次的验收清单。
