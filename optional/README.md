## 为什么默认不启用

规则越全，理解成本越高。

建议顺序：

1. 先用 `template/` 的空骨架跑两三个项目；
2. 当你**开始重复同一条要求**时（第三次说"别这样"），回来找对应那一条；
3. 只抄你真正踩过的那几条。

**整包照抄的结果通常是**：库里躺着 30 条规则，你一条都没记住，AI 也读不完。
